🔥 Tips & Tricks

Les astuces qui changent tout

Techniques concrètes testées par des milliers d'utilisateurs — du plus simple au plus avancé.

🦴 Classique

Le Caveman Prompting

Pas besoin de phrases élaborées. L'IA comprend très bien les commandes directes et minimalistes. Court = souvent meilleur. Comme un homme des cavernes : droit au but.

❌ "Pourriez-vous, si vous le voulez bien, rédiger pour moi un résumé de cette réunion en format structuré..." ✅ "Résume. 5 points. Ton pro. Max 80 mots."
🇬🇧 Astuce $$$

Prompter en anglais = meilleur + moins cher

Les LLMs sont entraînés majoritairement en anglais. Prompter en anglais améliore la qualité des réponses et consomme moins de tokens. Moins de tokens = moins cher pour l'entreprise. Vous pouvez quand même demander une réponse en français à la fin.

Prompt FR → réponse correcte, plus de tokens ✅ Prompt EN + "Answer in French" → meilleure qualité, ~20-30% moins de tokens
🎭 Role Prompting

Donner un rôle précis à l'IA

L'IA performe bien mieux quand on lui assigne une expertise précise dès le début. C'est la technique la plus simple et la plus impactante.

❌ "Écris une user story sur le login" ✅ "You are a senior PM at a French mortgage platform. Write a user story for..."
🔢 Structure

Numéroter ses contraintes

Pour des demandes complexes, listez vos contraintes en numéros. L'IA respecte beaucoup mieux une liste ordonnée qu'un paragraphe dense.

1. Réponse en français
2. Format tableau Jira
3. Max 5 lignes
4. Ton direct, sans formules de politesse
🪞 Chain of Thought

"Think step by step"

Ajouter cette phrase améliore drastiquement la qualité sur les sujets complexes. L'IA raisonne mieux quand elle externalise sa réflexion avant de conclure.

✅ "Think step by step. What are the main risks of removing the confirmation screen in our mortgage funnel?"
📌 Few-Shot

Donner des exemples (Few-Shot)

Montrer 1 ou 2 exemples du résultat attendu est souvent plus efficace que 10 lignes d'explication. L'IA imite le format avec une précision remarquable.

❌ "Écris un titre de ticket court et actionnable" ✅ "Write a ticket title like: 'Add CTA on summary page', 'Fix email on step 3'. Now write one for: [desc]"
♻️ Workflow

Itérer, pas recommencer

Ne relancez pas une nouvelle conversation si le résultat est imparfait. Affinez dans le même fil : l'IA garde le contexte et chaque itération est instantanée.

"Raccourcis le titre"
"Rends le 2ème critère plus précis"
"Ajoute un cas d'erreur"
"Traduis en anglais maintenant"
⚠️ Vigilance

Méfiance sur les chiffres & dates

Les LLMs inventent des statistiques avec une confiance absolue. Ne jamais utiliser un chiffre généré sans le sourcer. L'IA est excellente pour la structure — vous fournissez les vrais chiffres.

❌ "43% des clients abandonnent à l'étape 2" ← inventé ✅ Lui demander la structure, vous injectez vos données réelles
🎲 Créativité

Demander plusieurs variantes

Au lieu d'accepter la première proposition, demandez systématiquement des variantes. Le meilleur choix est souvent la variante B ou C. Ça prend 2 secondes de plus.

✅ "Give me 3 versions of this title: formal / neutral / punchy"
🧩 Structure avancée

Le prompt en 3 blocs

La structure la plus efficace pour des tâches complexes : Contexte + Tâche + Contraintes.

[Contexte] PM équipe crédit MeilleurTaux, tunnel de souscription
[Tâche] Write acceptance criteria for 2FA feature
[Contraintes] Gherkin format, 5 scenarios max, answer in English
🚀 VS Code

Les commandes "/" dans Copilot

Dans Copilot Chat, taper / affiche les commandes rapides. Parfait pour aller droit au but sans rédiger un prompt complet.

/explain → comprendre un fichier ou du code
/doc → générer de la documentation
/fix → corriger une erreur
/tests → générer des tests
🎯 Mindset

L'IA comme stagiaire brillant

Imaginez que vous briefez un stagiaire très intelligent mais sans contexte métier. Plus votre brief est précis, plus le résultat est pertinent. Un output médiocre vient presque toujours d'un brief insuffisant.

Brief vague → output générique inutilisable
Brief précis + contexte métier → output exploitable directement
✅ Bonnes pratiques

Les règles d'or

Ce qu'il faut faire, ne pas faire, et comment écrire un prompt efficace.

✅

À faire

  • Toujours relire et valider les outputs
  • Donner un contexte précis dans vos prompts
  • Itérer : affiner en plusieurs échanges
  • Préciser le format attendu (bullet points, tableau…)
  • Utiliser l'IA pour un premier jet, pas un output final
  • Tester plusieurs formulations si le résultat déçoit
  • Partager les bons prompts avec l'équipe crédit
  • Utiliser les outils approuvés par la DSI
⛔

À ne pas faire

  • Partager des données clients ou confidentielles
  • Copier-coller sans vérification (hallucinations !)
  • Utiliser des outils non approuvés sur données internes
  • Considérer l'IA comme une source de vérité absolue
  • Faire confiance aux chiffres sans les vérifier
  • Diffuser un output IA sans l'avoir relu
  • Utiliser ChatGPT public pour contenu sensible
  • Oublier que l'IA peut avoir des biais
⚠️

Sécurité des données : Ne jamais saisir de données personnelles clients, credentials, contrats ou informations financières dans des outils IA non approuvés. En cas de doute, contactez la DSI.

🎯 Exemple concret : mauvais vs bon prompt

Mauvais prompt

Fais-moi un ticket Jira pour la feature de login.

❌ Trop vague
Bon prompt (en anglais pour de meilleurs résultats)

You are a senior PM at MeilleurTaux, a French mortgage comparison platform.
Write a Jira ticket in French for this user story:
"As a logged-in user, I want to receive an email when my file moves to 'En cours d'instruction'."
Format: short title, description with context, acceptance criteria (bullet list), definition of done.

✓ Précis + EN
💻 Outils

VS Code & GitHub Copilot

Même sans être développeur, VS Code + Copilot est l'environnement le plus puissant pour travailler avec l'IA.

💡

Pourquoi VS Code pour les PMs ? VS Code n'est plus réservé aux devs. Avec GitHub Copilot, c'est un environnement IA ultra-puissant pour rédiger des specs, analyser des fichiers, et connecter vos outils (Jira, Confluence, Figma) via les MCPs.

📦 Installation étape par étape

1

Télécharger VS Code

Rendez-vous sur code.visualstudio.com → version macOS (Apple Silicon si Mac récent) → glissez dans Applications.

2

Installer l'extension GitHub Copilot

Extensions ⌘⇧X → rechercher GitHub Copilot → Installer. Installez aussi GitHub Copilot Chat pour le mode conversationnel.

3

Se connecter avec son compte GitHub

Cliquer sur l'icône compte en bas → "Sign in with GitHub" → autoriser dans le navigateur. Votre licence Copilot doit être activée (voir section Accès).

4

Ouvrir Copilot Chat

Raccourci ⌃⌘I ou icône Copilot dans la barre latérale. Le panneau de chat s'ouvre — dialoguez avec le contexte de tous vos fichiers ouverts.

5

Activer les MCPs (Jira, Confluence, Figma…)

Les MCPs connectent Copilot à vos outils. Voir la section MCP ci-dessous pour la configuration Jira pas à pas.

🛠 Usages concrets pour l'équipe crédit

📄

Rédaction de specs & PRDs

  • Ouvrez un fichier .md dans VS Code
  • Décrivez votre feature à Copilot Chat
  • Demandez un PRD avec contexte, user stories, KPIs
  • Itérez directement dans le même fil
📊

Analyse de données & CSV

  • Glissez un fichier CSV dans votre workspace
  • Demandez à Copilot d'analyser et trouver des tendances
  • Générez des scripts pour traiter la data
  • Pas besoin de coder — Copilot écrit, vous lisez
🔄

Refactoring de documents

  • Sélectionnez un texte → "Copilot: Edit"
  • Simplifier, traduire, reformuler en un clic
  • Notes de réunion → action items structurés
  • Emails → tickets Jira prêts à créer
🤖

Automatisations légères

  • Scripts de renommage / traitement de fichiers
  • Extraction de données depuis des JSONs
  • Génération de templates répétitifs
  • Formatage de données pour import Jira
⌨️

Raccourcis clés : ⌃⌘I Ouvrir Copilot Chat · ⌘K Inline Edit · Tab Accepter suggestion · Esc Refuser · /explain /fix /doc Commandes rapides

🔌 MCP

Ce qu'on peut faire avec MCP Jira

Le Model Context Protocol connecte GitHub Copilot directement à Jira. Finis les copy-pastes entre onglets !

🧩

C'est quoi un MCP ? Un pont entre votre IA et vos outils (Jira, Confluence, Figma, GitHub…). Une fois configuré dans VS Code, vous pouvez demander à Copilot de lire, créer et modifier des tickets Jira directement depuis le chat.

⚡ Actions disponibles avec MCP Jira

Action Ce que vous dites à Copilot Résultat Niveau
Créer un ticket "Crée un ticket dans le projet X pour la user story : [desc]" Ticket créé avec titre, description, type, priorité ✓ Simple
Lire des tickets "Montre les tickets ouverts dans le sprint actuel du projet Y" Liste avec statuts, assignés, priorités ✓ Simple
Mettre à jour "Change le statut de MTX-1234 en 'En cours', assigne à Marie" Ticket mis à jour en temps réel dans Jira ✓ Simple
Commenter "Ajoute un commentaire sur MTX-567 : 'POC validé front, en attente back'" Commentaire posté dans Jira ✓ Simple
Rechercher "Trouve tous les bugs High liés au tunnel de souscription crédit" Résultats JQL filtrés et lisibles ✓ Simple
Créer en batch "À partir de ce PRD, génère les user stories et crée-les dans Jira" Création automatique de plusieurs tickets ⚡ Avancé
Résumer un epic "Résume l'avancement de l'epic MTX-100 avec ses sous-tickets" Synthèse narrative du périmètre et de l'avancement ⚡ Avancé
Lier des tickets "Crée un lien 'bloque' entre MTX-200 et MTX-201" Dépendance créée entre les deux tickets ✓ Simple

⚙️ Configuration du MCP Jira dans VS Code

1

Générer un token API Jira

Allez sur id.atlassian.com/manage-profile/security/api-tokens → Créer un token → Copiez-le (affiché une seule fois).

2

Ouvrir les paramètres VS Code

⌘⇧P → "Open User Settings (JSON)" → ajouter la configuration MCP dans la section mcp.servers.

3

Configurer le serveur MCP Atlassian

Renseigner ATLASSIAN_EMAIL, ATLASSIAN_TOKEN et l'URL de l'instance : meilleurtaux.atlassian.net.

4

Tester la connexion

Dans Copilot Chat, tapez : "Liste les projets Jira disponibles". Si ça marche, Copilot liste vos projets en quelques secondes. 🎉
